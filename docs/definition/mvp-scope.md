# MVP Scope

## Scope Items

## IN

- User registration and authentication
- Registration and configuration of software projects (including their source code location).
- Running security scans on a registered project.
- Managing scan status (pending, in progress, completed, failed).
- Scan history by project.
- Integration and orchestration of external security tools.
- Collection of results generated by integrated tools.
- SAST (Static Application Security Testing) analysis.
- Secret Scanning (detection of exposed credentials, tokens, and secrets).
- Support for running multiple types of analyses through the same platform.
- Processing of the various report formats generated by the tools.
- Standardization of findings into a common internal format.
- Identification of the source tool for each finding.
- Logging, classification, location, and severity of findings.
- Centralized interface for viewing security results.
- Filtering of findings by type, severity, scan, or tool.
- Viewing results by specific scan.
- Retention of historical results across scans.
- Overview of a project’s security status.


## OUT

- Integration with DAST.
- Integration with SCA (dependency analysis).
- IaC or container scanning.
- Automatic remediation of findings.
- Native mobile app.
- Offline data capture.


## LATER

- Port scanning on a configured target.
- Development of proprietary/custom security scanners within the platform.
- Integration with external ticketing systems (Jira, Azure DevOps).
- Automatic notifications for critical findings.
- Executive dashboard with metrics and historical trends.
- Report export (PDF, CSV).
- Correlation and deduplication of findings across different tools of the same type.
- Public API and connector marketplace for third-party integrations.


## UNKNOWN

- Multi-tenant support from the start.
- SSO/integration with a corporate identity provider.
- Expected volume of daily scans/results.
- Specific SAST and secret scanning tools to be integrated into the MVP.
- Historical data retention policy.
